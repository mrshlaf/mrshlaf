### [Lapak UI — Marketplace & Community Platform](https://github.com/mrshlaf/lapak-ui)
`Apr 2026 — May 2026`

Architected a peer-to-peer marketplace and social community platform for Universitas Indonesia students. Features an anti-ghosting COD reservation engine backed by Upstash Redis TTL counters, product-linked real-time chat via Supabase WebSockets, and a multi-channel notification system (in-app, Telegram Bot API, Resend email). Backed by a strictly normalized 3NF PostgreSQL schema via Prisma ORM.

`Next.js` `TypeScript` `PostgreSQL` `Prisma ORM` `Redis` `Supabase` `Telegram Bot API`

### [Folio — Tiered Dynamic Bookstore Catalog](https://github.com/mrshlaf/folio)
`Apr 2026 — May 2026`

Engineered a NoSQL MongoDB bookstore solving scalability bottlenecks through dynamic Hot/Cold data tiering — reducing document size by up to 75%. Automated shelf-promotion via a background node-cron worker, implemented pre-aggregated Summary Blobs for instant catalog browsing, and a Bayesian 3D weighted rating system with time-decay. MongoDB single-document fetch **outperformed Neon SQL by 28.2x** in load-tested benchmarks via k6.

`MongoDB` `Node.js` `NoSQL Architecture` `node-cron` `k6` `Performance Benchmarking`

</td>

### [Computer Price Prediction — ML (CRISP-DM)](https://github.com/mrshlaf/data-analytics-computer-price-prediction)
`Apr 2026 — May 2026`

End-to-end machine learning pipeline on 100,000+ dataset rows using the CRISP-DM methodology. Achieved **87.85% R-squared** accuracy and a $157.13 Mean Absolute Error with a Random Forest Regressor, outperforming KNN and SVR. Applied IQR Winsorization for outlier treatment, Wrapper (RFE) feature selection to minimize multicollinearity, and generated 20 high-quality statistical visualizations.

`Python` `Scikit-Learn` `Random Forest` `Pandas` `Matplotlib` `Seaborn` `CRISP-DM`
